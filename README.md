# 📰 E-News Portal

A modern and responsive news publishing platform built with React (Vite), Node.js, Express, and MongoDB.
The platform supports a multi-role content workflow (Reporter → Writer → Editor → Admin) to ensure quality news publication before articles go live.

The system simulates a real-world digital newsroom, where news passes through different review stages before being published.

#  🚀 Features

- 🖊️ Role-based content creation (Writer, Editor, Admin)
- 🗂️ Category management with SEO-friendly slugs
- 📝 Rich-text article editor with image upload (Cloudinary / Multer)
- 🔁 Article workflow system (Draft → Review → Approve → Publish)
- 🔎 Search, pagination, and category filters
- 📱 Fully responsive UI (mobile + desktop)
- 🔐 Secure authentication using JWT + bcrypt
- ⚡ Fast frontend performance with React + Vite
- 📈 View counts, trending & recent articles
- 🛠️ RESTful API with centralized error handling
